# 电解功能修改与验证记录

实施日期：2026-09-09。

## 最终行为
- 每次关机到开机产生一轮待运行任务，首次满足已确认有水、水箱在位、非风干后启动。
- 从真正输出起累计180000个10ms节拍（30分钟），每6000节拍切换方向。
- 起始输出P_DJ1/P_DJ2=10，之后10/01交替；共29次换向。
- 每次换向先输出00，下一10ms节拍输出相反方向。关断间隔计入30分钟，因此实际通电时间比1800秒少约0.29秒。
- 满30分钟输出00，本次开机不再启动。
- 运行中确认缺水、提箱、进入风干或自检，结束本轮，不自动续跑。重新开机才重置完整周期。
- 等待期间缺水/无箱不计时，条件恢复后可启动。仅模式/档位变化不重置周期。
- 主循环末尾每圈检查关断条件；物理缺水和提箱沿用原检测消抖（缺水约2秒、提箱500ms），不是原始引脚变化立即关断。
- 电解启动水位确认要求恰好一个霍尔连续触发2秒，避免上电默认状态造成误启动。

## 修改文件
- c/Function/Function.c：新增独立F_mElectrolysisControl状态机。
- c/Function/Function.h：声明新入口。
- c/SenseDeal/SenseDeal.c、.h：电解启动用的有水确认标志。
- c/Main/main.c：主循环末尾调用电解控制，自检也经过关断判断。
- 所有源文件以PowerShell代码页936读写，并通过字节往返检查；原文件副本位于before目录。

## 硬件依据
电解板BOM（20260203版）IC2为MX510HC。其Rev1.0手册第8页确认SEL1=1普通H桥模式下：00高阻待机，10正转，01反转。实际板应处于用户描述的H桥输入模式。软件选择10ms换向关断间隔，尚未进行实板波形测量。
